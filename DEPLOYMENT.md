# 🚀 Deployment Guide

## Quick Start

Your portfolio is ready to deploy to Vercel. Follow these steps:

### 1. Environment Variables

Sign up at [resend.com](https://resend.com) and get your API key.

### 2. Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. Click **"Add New Project"**
3. Import: `SarmadShafiq123/Sarmad-Portfolio`
4. Add environment variables:
   - `RESEND_API_KEY` = Your Resend API key
   - `CONTACT_EMAIL` = Your email address
5. Click **Deploy**

### 3. After Deployment

Update `src/data/index.js` → Portfolio project → `liveUrl` with your deployed URL.
